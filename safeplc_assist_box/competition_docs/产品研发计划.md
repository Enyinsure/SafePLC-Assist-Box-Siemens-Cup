# SafePLC-Assist Box 产品研发计划

本文档说明 SafePLC-Assist Box 的产品研发计划。项目定位为面向西门子杯的工业知识安全问答终端原型，重点包括工业手册知识问答、安全风险判断、Evidence Confidence、Answer-Evidence Check、结构化证据卡片、本地图文证据显示、离线只读边界和实体终端原型设计。

---

## 1. 产品愿景

SafePLC-Assist Box 目标是成为离线、只读的工业知识辅助终端，帮助用户以更安全、更可追溯的方式理解工业手册知识。

系统不是 PLC 控制器，不连接真实 PLC，不接入 TIA Portal，也不替代具备资质的工程师。

产品愿景为：

```text
工业知识问答
+
安全边界
+
证据复核
+
本地图文证据
+
实体终端形态
```

---

## 2. 产品定位

SafePLC-Assist Box 位于软件问答系统和工业培训终端之间。

它不是普通聊天机器人，不是普通搜索引擎，也不是 PLC 控制器。

它具备以下特征：

- 离线 / 只读边界
- 面向工业手册的知识问答
- 安全风险判断
- Evidence Confidence
- Answer-Evidence Check
- 结构化证据卡片
- 本地图文证据显示
- Streamlit 产品界面
- 实体终端原型设计

---

## 3. 目标用户

| 用户类型 | 需求 |
|---|---|
| 学生和学习者 | 学习西门子 PLC 相关工业知识 |
| 竞赛评审 | 审查系统能力、安全边界和产品形态 |
| 工业培训用户 | 在培训场景理解手册知识 |
| 维护辅助用户 | 查询参数、模块和安全说明 |
| 教师和演示者 | 展示证据化工业问答流程 |

系统用于训练、学习、竞赛评审和原型演示，不用于真实工业部署。

---

## 4. 核心问题与产品响应

| 问题 | 产品响应 |
|---|---|
| 工业手册长且难查 | 面向手册知识的问答与检索 |
| 用户问题缺少型号或参数上下文 | 问题分类与澄清逻辑 |
| 回答可能缺少证据支撑 | Evidence Confidence 与 Answer-Evidence Check |
| PLC 问题可能涉及安全风险 | 安全风险判断与离线只读边界 |
| 纯文本回答难以复核 | 结构化证据卡片 |
| 缺少图文追溯 | 本地图文证据显示 |
| 纯软件演示产品形态不足 | 实体终端原型设计 |

---

## 7. 硬件原型计划

硬件原型采用方案 B：

```text
外置计算主机 + 产品化实体终端外壳
```

笔记本作为外置计算主机。实体终端外壳仍在进行中，计划提供：

- 显示区域
- 产品铭牌
- SAFE / CAUTION / HIGH_RISK / CHECK 指示
- Query / Demo / Export Log 按钮
- OFFLINE / READ-ONLY 标签
- PLC CONTROL DISABLED 标签
- KNOWLEDGE QA ONLY 标签

实体终端不连接真实 PLC，不执行控制动作。

---

## 9. 当前限制

- 公开仓库不包含完整西门子手册。
- 公开仓库不包含完整 OCR 输出。
- 公开仓库不包含向量库。
- 公开仓库不包含模型权重。
- 公开仓库不包含完整图文证据资产。
- 实体终端外壳仍在进行中。
- 最终照片和演示视频后续补充。

---

## 10. 总结

SafePLC-Assist Box V1.2 已完成核心软件原型和关键安全问答模块。后续研发重点是实体终端外壳、最终照片、最终演示视频和竞赛提交材料完善。
