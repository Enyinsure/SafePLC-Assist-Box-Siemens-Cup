# SafePLC-Assist Box 西门子杯答辩 PPT 大纲

## 1. 封面
SafePLC-Assist Box：面向 S7-1500 / ET 200MP 的多模态工业知识 Agent 与安全运维助手

## 2. 项目背景
工业手册资料庞大，新人工程师查找参数、接口图、接线图和安全说明效率低。

## 3. 用户痛点
- 查手册慢
- 型号不清容易误查
- 图文证据难定位
- 普通大模型可能幻觉或输出危险建议

## 4. 产品定位
面向智能制造现场、高校实训和新人培训的工业知识安全问答终端。

## 5. 系统架构
前端产品化界面 + Agent v2 澄清 + Safety Guard v1 + 多模态 RAG + S7 手册证据库。

## 6. 核心功能
- 工业知识问答
- 多模态证据检索
- 缺少型号主动追问
- 危险操作拒答
- 运维记录生成

## 7. 典型演示
- 缺少型号主动追问
- PS 60W 电源参数查询
- PROFINET 环网图文证据
- CPU X1/X2 接口图证据
- 短接安全回路拒答

## 8. 创新点
- 面向工业手册的多模态 RAG
- 面向运维场景的 Agent 澄清
- 工业安全护栏
- 证据页码与图文证据增强
- 产品化运维记录输出

## 9. 原型展示
笔记本 + 展示板 + 模拟 S7 模块卡片 + 典型问题卡片 + 运维记录卡片。

## 10. 测试结果
展示已通过的 6 类典型案例和前端验收结果。

## 11. 应用价值
提升查询效率、降低培训成本、减少误操作风险、辅助高校实训教学。

## 12. 后续规划
扩展更多手册、支持企业知识库、部署到工业平板或边缘计算盒。
