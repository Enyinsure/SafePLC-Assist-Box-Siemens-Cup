# SafePLC-Assist Box 商业计划书

SafePLC-Assist Box 是面向西门子杯自由探索赛道的工业知识安全问答终端原型。项目聚焦工业手册知识问答、安全风险判断、Evidence Confidence、Answer-Evidence Check、结构化证据卡片、本地图文证据显示、离线只读边界和实体终端原型设计。

---

## 1. 产品概述

SafePLC-Assist Box 是离线、只读的工业知识问答和证据复核终端。系统帮助用户围绕西门子 S7-1500 / ET 200MP 相关手册知识提出问题，并获得带证据追溯的回答。

项目不是普通聊天机器人，不是普通搜索引擎，也不是 PLC 控制器。

产品定位为：

```text
工业知识问答终端
+
安全边界
+
Evidence Confidence
+
Answer-Evidence Check
+
结构化证据卡片
+
本地图文证据显示
+
实体终端原型
```

---

## 2. 问题背景

工业手册通常篇幅大、内容复杂、检索困难。在 PLC 学习、培训和维护辅助场景中，用户可能面临：

| 问题 | 说明 |
|---|---|
| 手册负担重 | 工业手册页数多、技术细节密集 |
| 问题上下文不足 | 用户可能缺少模块、型号或参数信息 |
| 回答缺少证据 | 普通模型回答可能没有明确证据支持 |
| 安全风险 | PLC 问题可能涉及写入、下载、启停或控制动作 |
| 可追溯性弱 | 纯文本回答难以审计 |
| 产品形态弱 | 纯软件页面不像完整竞赛产品 |

---

## 3. 目标用户

| 用户类型 | 需求 |
|---|---|
| 学生和学习者 | 学习西门子 PLC 相关知识 |
| 竞赛评审 | 审查原型能力和安全边界 |
| 工业培训用户 | 在培训环境中理解手册知识 |
| 维护辅助用户 | 查询参数、模块和安全说明 |
| 教师和演示者 | 展示证据化工业问答流程 |

该产品主要面向教育、培训、竞赛评审和原型演示，不用于真实工业控制。

---

## 4. 产品价值

### 4.1 提升工业知识查找效率

系统帮助用户更快定位手册知识，减少手动翻阅长文档的负担。

### 4.2 提升安全性

系统通过安全边界和安全风险判断，避免输出真实 PLC 控制指令或危险操作步骤。

### 4.3 提供证据化复核

Evidence Confidence 与 Answer-Evidence Check 帮助用户判断回答是否有证据支撑。

### 4.4 提升可追溯性

结构化证据卡片和本地图文证据显示使证据链比纯文本更易评审。

### 4.5 提升竞赛产品形态

实体终端设计使系统更像完整工业产品原型，而不是单纯网页。

---

## 5. 差异化

| 对比对象 | 局限 | SafePLC-Assist Box 差异 |
|---|---|---|
| 关键词搜索 | 只返回匹配文本 | 输出回答、证据置信度和证据卡片 |
| 通用聊天机器人 | 可能生成无依据内容 | 增加 Answer-Evidence Check |
| 基础 RAG 演示 | 通常缺少安全边界 | 增加工业安全风险判断 |
| 纯文本检索系统 | 图文追溯弱 | 支持本地图文证据显示 |
| 纯软件演示 | 产品形态弱 | 增加实体终端原型设计 |
| PLC 控制工具 | 可能涉及操作风险 | 本系统离线、只读、不连接真实 PLC |

---

## 6. 安全边界

SafePLC-Assist Box 不执行：

- 连接真实 PLC
- 接入 TIA Portal
- PLC 通信
- PLC 写入、下载、启停或控制动作
- 真实 IT / OT 网络数据采集
- 替代西门子官方手册或具备资质的工程师

---

## 7. 应用场景

- 工业教育辅助
- 竞赛原型展示
- 工业培训环境
- 维护知识辅助
- 教学演示和证据复核

系统不替代现场规程和专业工程判断。

## 9. 风险分析

| 风险 | 应对 |
|---|---|
| 版权敏感资料不能公开 | 公开仓库不包含完整西门子手册和完整图文证据资产 |
| 本地环境资产体积较大 | 公开仓库不包含完整 OCR 输出、向量库、模型权重和压缩包 |
| PLC 问题可能涉及危险操作 | 系统加入安全边界和安全风险判断 |
| 评测范围有限 | 当前报告明确说明模块级评测范围 |
| 实体原型未完全完成 | 文档说明当前设计和后续完善计划 |

---

## 10. 总结

SafePLC-Assist Box 的价值不只是回答问题，而是让工业问答更安全、更可追溯、更适合评审。当前版本适合软件级和文档级评审，实体外壳、最终照片和演示视频将在后续完善阶段补充。
