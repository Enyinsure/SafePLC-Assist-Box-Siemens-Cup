# SafePLC-Assist Box 产品设计与研发计划书

## 1. 当前版本
V1 原型版本：基于 SafePLC-Agent 技术底座，完成产品化前端、典型案例、证据卡片和运维记录生成。

## 2. 已完成能力
- 多模态手册 RAG
- Agent v2 主动澄清
- Safety Guard v1 工业安全护栏
- Streamlit 产品化前端
- 典型案例演示
- 运维辅助记录生成

## 3. 研发路线

### V1：竞赛展示原型
完成西门子杯演示闭环，重点展示工业知识问答、图文证据、主动追问和危险操作拒答。

### V2：教学实训版本
增加教师案例库、学生练习题、手册定位训练和答题记录导出。

### V3：企业运维版本
支持企业内部手册、设备台账、维修记录和知识库接入。

### V4：边缘部署版本
迁移到工业平板、边缘计算盒或企业内网服务器。
