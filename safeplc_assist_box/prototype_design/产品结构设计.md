# SafePLC-Assist Box 产品结构设计

本文档说明 SafePLC-Assist Box 的产品结构设计。产品结构将软件智能、证据复核、安全边界和实体终端形态组合在一起，形成工业知识安全问答终端原型。

---

## 1. 产品结构总览

SafePLC-Assist Box 的结构为：

```text
软件问答系统
+
证据复核层
+
安全边界层
+
产品化实体终端外壳
```

系统不是 PLC 控制器，而是离线、只读的工业知识问答和证据复核终端。

---

## 2. 总体组成

```text
用户
->
实体终端界面

外置计算主机

->
Evidence Confidence

Answer-Evidence Check
->
结构化证据卡片
->
本地图文证据显示
```

---

## 3. 软件结构

| 层级 | 功能 |
|---|---|
| 产品界面层 | 提供 Streamlit 界面和产品展示 |
| 问题理解层 | 分类用户问题并识别缺失上下文 |
| 安全边界层 | 识别潜在危险工业操作请求 |
| 问答响应层 | 生成或呈现基于手册知识的回答 |
| 证据复核层 | 提供 Evidence Confidence 与 Answer-Evidence Check |
| 证据卡片层 | 将证据转换为结构化可复核卡片 |
| 图文证据层 | 在本地演示环境中显示图文证据 |

## 5. 硬件结构

硬件原型采用方案 B：

```text
外置计算主机 + 产品化实体终端外壳
```

外置计算主机运行软件系统。实体终端外壳提供显示区域、产品铭牌、状态指示、Query / Demo / Export Log 按钮、安全边界标签和工业产品形态。

---

## 6. 安全边界结构

软件和硬件都要展示安全边界。

系统不连接真实 PLC，不接入 TIA Portal，不执行 PLC 通信、写入、下载、启停或控制动作，不采集真实 IT / OT 网络数据。

实体终端应显示：

```text
OFFLINE / READ-ONLY
PLC CONTROL DISABLED
KNOWLEDGE QA ONLY
```

---

## 7. 证据结构

证据结构包括三个层级：

1. Evidence Confidence：判断回答是否有充分证据支持。
2. Answer-Evidence Check：检查回答关键声明是否被证据支持。
3. 结构化证据卡片：输出 page、figure_id、source、title、module、parameter、snippet、confidence 等字段。

---

## 8. 本地图文证据结构

当证据卡片包含页码或 `figure_id` 时，前端尝试查找对应本地图文证据文件。

示例：

```text
page: 641
figure_id: page_0641_visual
```

对应文件示例：

```text
page_0641.jpg
```

公开仓库不包含完整图文证据资产、完整西门子手册、完整 OCR 输出、向量库或模型权重。

---

## 9. 软件到硬件映射

| 软件状态 | 实体终端指示 |
|---|---|
| 低风险知识查询 | SAFE |
| 缺少关键上下文 | CAUTION |
| 中风险或需要复核 | CAUTION |
| 高风险 PLC 操作请求 | HIGH_RISK |
| Evidence Confidence 完成 | CHECK |
| Answer-Evidence Check 完成 | CHECK |
| 无证据支撑声明 | CAUTION |
| 不安全控制请求 | HIGH_RISK |

## 11. 总结

SafePLC-Assist Box 的产品结构支持软件级评审、文档级评审和后续实体原型展示。它强调工业知识问答、安全风险判断、Evidence Confidence、Answer-Evidence Check、结构化证据卡片、本地图文证据显示和实体终端产品形态。
