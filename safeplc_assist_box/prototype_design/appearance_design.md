# SafePLC-Assist Box 外观设计说明

## 1. 外观设计目标
外观设计强调工业风、清晰、简洁和可展示性，突出“工业知识问答终端”“证据页码”“图文证据”“安全运维提醒”。

## 2. 桌面原型展示套件方案
采用低风险、低成本的桌面展示套件：
- 笔记本电脑运行前端。
- A3/A2 展示板展示产品名称、架构和功能。
- 模拟 S7 模块卡片展示典型设备。
- 典型问题卡片引导评委体验。
- 运维记录卡片展示产品化输出。

## 3. 笔记本 + 展示台方案
笔记本作为本地计算单元和显示单元。后续可迁移到工业平板、边缘计算盒或企业内网服务器。

## 4. 铭牌设计
铭牌内容：
SafePLC-Assist Box  
工业知识安全问答终端  
面向 S7-1500 / ET 200MP 的多模态工业知识 Agent 与安全运维助手

## 5. 模拟模块卡片设计
建议制作四类卡片：
- CPU 1517-3 PN
- PS 60W 24/48/60VDC HF
- ET 200MP
- PROFINET HMI

## 6. 展台布局说明
左侧放产品铭牌和应用场景，中间放笔记本前端，右侧放模拟模块卡片和典型问题卡片，下方放运维记录卡片。
