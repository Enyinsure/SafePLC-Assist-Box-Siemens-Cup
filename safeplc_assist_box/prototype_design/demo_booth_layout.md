# SafePLC-Assist Box 展台布局方案

## 1. 展台主题
SafePLC-Assist Box：工业知识安全问答终端

## 2. 布局
- 中央：笔记本电脑，打开产品化前端。
- 左侧：产品介绍展示板。
- 右侧：模拟 S7 模块卡片。
- 前方：典型问题卡片。
- 下方：运维辅助记录样张。

## 3. 展示顺序
1. 介绍工业手册复杂、查找困难的痛点。
2. 展示产品首页。
3. 演示缺少型号时主动追问。
4. 演示补充型号后返回参数和页码。
5. 演示 PROFINET 图文证据查询。
6. 演示危险操作拒答。
7. 展示运维辅助记录生成。

## 4. 答辩说明
本原型采用笔记本作为本地计算单元，不连接真实 PLC，不执行控制动作，重点验证工业手册多模态知识检索、Agent 澄清、安全护栏和产品化交互。
