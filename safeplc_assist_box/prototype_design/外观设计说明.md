# SafePLC-Assist Box 外观设计说明

本文档说明 SafePLC-Assist Box 实体终端原型的外观设计。外观设计目标是让项目呈现为产品化工业知识安全问答终端，而不是普通软件演示页面。

---

## 1. 设计概念

SafePLC-Assist Box 是离线、只读的工业知识问答终端。

外观应传达三个关键词：

```text
工业
安全
证据化
```

实体终端应清楚表达：

- 这是知识辅助终端。
- 这是证据复核终端。
- 系统离线、只读。
- 系统不是 PLC 控制器。
- 系统不连接真实 PLC。

---

## 2. 整体外观方向

| 设计方面 | 方向 |
|---|---|
| 整体风格 | 工业终端 / 工程设备风格 |
| 主色 | 白、灰、黑、蓝灰等中性工业色 |
| 前面板 | 清晰显示区域、状态指示和标签 |
| 交互 | Query / Demo / Export Log 按钮 |
| 安全标签 | 明显展示离线和禁用控制边界 |
| 产品识别 | 清晰 SafePLC-Assist Box 铭牌 |

---

## 3. 产品铭牌

前面板应包含产品铭牌：

```text
SafePLC-Assist Box V1.2
工业知识安全问答终端
```

铭牌应位于前面板顶部，便于评审者快速识别产品身份。

---

## 4. 显示区域

显示区域是终端主要视觉焦点，应展示 Streamlit 产品界面，包括：

- 问题输入区
- 安全边界面板
- Evidence Confidence 面板
- Answer-Evidence Check 面板
- 结构化证据卡片面板
- 本地图文证据显示区域

---

## 5. 状态指示

前面板建议包含四类状态指示：

```text
SAFE
CAUTION
HIGH_RISK
CHECK
```

| 指示 | 含义 |
|---|---|
| SAFE | 低风险知识查询 |
| CAUTION | 需要复核或上下文不完整 |
| HIGH_RISK | 潜在危险工业操作请求 |
| CHECK | 证据检查完成 |

---

## 6. 按钮设计

终端可包含三个产品交互按钮：

```text
Query
Demo
Export Log
```

这些按钮是产品交互隐喻，用于让原型更像终端设备。当前主要交互仍由 Streamlit 软件界面完成。

---

## 7. 安全边界标签

前面板必须明显显示：

```text
OFFLINE / READ-ONLY
PLC CONTROL DISABLED
KNOWLEDGE QA ONLY
```

这些标签用于避免评审者误解系统能够控制真实 PLC。

---

## 9. 视觉传达目标

| 信息 | 传达方式 |
|---|---|
| 这是工业知识问答终端 | 产品铭牌和终端外壳 |
| 系统具备安全意识 | SAFE / CAUTION / HIGH_RISK 指示 |
| 系统具备证据复核 | CHECK 指示和证据面板 |
| 系统不是 PLC 控制器 | PLC CONTROL DISABLED 标签 |
| 系统离线只读 | OFFLINE / READ-ONLY 标签 |
| 系统具备产品形态 | 实体外壳、按钮、指示灯和布局 |

---

## 10. 当前状态

当前外观设计属于实体原型计划设计。软件系统已经实现并可在外置计算主机运行。实体外壳、标签、指示灯和最终外观照片仍在后续完善阶段。

---

## 11. 总结

SafePLC-Assist Box 的外观设计服务于“工业知识安全问答终端”这一核心定位。外观不应夸大真实工业控制能力，而应强调知识辅助、证据复核、安全边界、离线只读和产品化终端形态。
