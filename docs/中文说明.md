# SafePLC-Assist Box 中文说明

SafePLC-Assist Box 是面向西门子杯自由探索赛道的工业知识安全问答终端原型。项目围绕西门子 S7-1500 / ET 200MP 等工业手册知识，构建一个具备安全边界、证据追溯、结构化证据卡片、本地图文证据显示和答案一致性检查能力的产品化原型系统。

本项目不是普通搜索引擎，不是通用聊天机器人，也不是 PLC 控制器。它面向教学、实训、竞赛评审和原型验证场景，帮助用户在离线、只读、可追溯的边界内理解工业手册知识。

---

## 1. 项目定位

SafePLC-Assist Box 的核心定位是：

```text
工业知识安全问答终端
+
安全风险判断
+
Evidence Confidence
+
Answer-Evidence Check
+
结构化证据卡片
+
本地图文证据显示
+
实体终端原型设计
```

系统重点解决以下问题：

| 问题 | 项目应对方式 |
|---|---|
| 工业手册篇幅长、查找困难 | 面向手册知识的问答和证据检索 |
| 用户问题可能缺少型号或上下文 | 问题分类与澄清提示 |
| 普通大模型可能输出无依据结论 | Evidence Confidence 与 Answer-Evidence Check |
| PLC 问题可能涉及危险操作 | 安全风险判断与离线只读边界 |
| 纯文本回答不便复核 | 结构化证据卡片与本地图文证据显示 |
| 纯软件页面产品感不足 | 实体终端原型设计 |

---

## 2. 技术边界

SafePLC-Assist Box 明确不执行以下行为：

- 不连接真实 PLC
- 不接入 TIA Portal
- 不执行 PLC 通信
- 不执行 PLC 写入、下载、启停或控制动作
- 不采集真实 IT / OT 网络数据
- 不替代西门子官方手册、现场安全规程或具备资质的工程师判断

系统只用于工业知识问答、证据复核、安全提醒、教学演示和竞赛原型展示。

## 4. 核心能力

### 4.1 安全感知问答

系统会区分普通知识问题、参数查询、连接说明、安全相关问题和高风险操作请求。对于可能涉及真实 PLC 写入、下载、启停、强制输出或绕过安全回路的问题，系统不会提供可执行控制步骤，而是提示官方资料、现场规程和专业工程复核。

### 4.2 Evidence Confidence

Evidence Confidence 用于判断当前回答是否有足够证据支持。典型结果包括：

- High
- Medium
- Low
- Conflict

该能力帮助评审者和使用者区分“证据较充分的回答”和“需要人工复核的回答”。

### 4.3 Answer-Evidence Check

Answer-Evidence Check 用于检查回答中的关键声明是否能被当前证据支持。典型结果包括：

- PASS
- REVIEW
- FAIL

该能力使系统输出更适合审查，而不是只给出不可追溯的自然语言回答。

### 4.4 结构化证据卡片

系统会输出结构化证据卡片，常见字段包括：

- page
- figure_id
- source
- title
- module
- parameter
- snippet
- confidence

证据卡片让回答来源、页码、模块和片段更容易被评审者复核。

### 4.5 本地图文证据显示

当证据卡片包含页码或 `figure_id` 时，前端会在本地演示环境中尝试查找对应图文证据文件并显示。

示例：

```text
page: 641
figure_id: page_0641_visual
```

对应本地图文证据文件示例：

```text
page_0641.jpg
```

完整图文证据资产不包含在公开仓库中，仅在本地演示环境中使用。

## 5. 公开仓库边界

公开仓库不包含：

- 完整西门子手册
- 完整 OCR 输出
- 向量库
- 模型权重
- 完整图文证据资产
- 大型压缩交付包
- 私钥、token 或环境文件

这些内容因仓库体积、版权、隐私和安全边界原因不放入公开仓库。公开仓库主要保留代码、评测文件、报告、硬件设计文档和竞赛说明材料。

## 8. 硬件原型

项目采用方案 B：

```text
外置计算主机 + 产品化实体终端外壳
```

当前阶段使用笔记本作为外置计算主机，实体外壳用于展示产品形态、状态指示、按键隐喻和安全边界标签。实体外壳仍在进行中，最终照片和演示视频将在原型完善后后续补充。

实体终端不是 PLC 控制器，不连接真实 PLC，也不执行任何控制动作。
