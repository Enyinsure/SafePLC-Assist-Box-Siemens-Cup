# SafePLC-Assist Box 中文说明

SafePLC-Assist Box 是面向西门子杯自由探索赛道的工业知识安全问答终端原型。

项目围绕西门子 S7-1500 / ET 200MP 等工业手册知识，构建一个具备安全边界、证据追溯、图文证据展示和答案一致性检查能力的产品化原型系统。

---

## 一、项目定位

本项目不是普通搜索引擎，也不是简单 RAG 问答页面。

项目目标是构建一个面向工业知识辅助的安全问答终端，重点包括：

- 工业手册知识检索
- 工业安全风险分级
- 问题类型分类与路由
- Evidence Confidence 证据置信度评估
- Answer-Evidence Check 答案-证据一致性检查
- V1.1 证据卡片面板
- 图文证据图片展示
- OFFLINE / READ-ONLY 安全边界
- Streamlit 产品化前端
- 外置计算主机 + 实体终端盒子方案

---

## 二、技术边界

本系统不连接真实 PLC，不接入 TIA Portal，不执行任何 PLC 下载、写入、启停或控制动作，不采集真实 IT / OT 网络数据。

系统定位为：

- 工业知识问答辅助工具
- 证据追溯工具
- 安全提示工具
- 教学演示工具
- 竞赛原型系统

系统不能替代西门子官方手册、现场安全规程或具备资质的工程人员判断。

---

## 三、核心功能

### 1. 工业安全问答

系统会对输入问题进行工业场景判断，区分普通知识问题、配置类问题、维护类问题和潜在高风险操作问题。

### 2. 证据置信度评估

系统会判断当前答案是否具备足够证据支撑，并输出证据置信度，例如：

- High
- Medium
- Low
- Conflict

### 3. 答案-证据一致性检查

系统会检查答案中的关键声明是否能够被当前证据支持，并给出：

- PASS
- REVIEW
- FAIL

### 4. V1.1 证据卡片

系统会生成结构化证据卡片，包括：

- page
- figure_id
- source
- title
- module
- parameter
- snippet
- confidence
