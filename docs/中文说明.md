# SafePLC-Assist Box 中文说明

SafePLC-Assist Box 是面向西门子杯自由探索赛道的工业知识安全问答终端原型。

本项目围绕西门子 S7-1500 / ET 200MP 等工业手册知识，构建一个具备安全边界、证据追溯、图文证据显示和答案一致性检查能力的产品化原型系统。

## 二、项目定位

本项目不是普通搜索引擎，也不是简单的 RAG 问答页面。

项目目标是构建一个面向工业知识辅助的安全问答终端。系统不仅回答问题，还会给出证据置信度、答案-证据一致性检查结果和原始图文证据。

项目重点包括：

- 工业手册知识检索
- 工业安全风险分级
- 问题类型分类与路由
- 证据置信度评估
- 答案-证据一致性检查
- 结构化证据卡片
- 图文证据图片显示
- 离线 / 只读安全边界
- Streamlit 产品化前端
- 外置计算主机 + 实体终端盒子方案

---

## 三、技术边界

本系统不连接真实 PLC，不接入 TIA Portal，不执行任何 PLC 下载、写入、启停或控制动作，不采集真实 IT / OT 网络数据。

系统定位为：

- 工业知识问答辅助工具
- 证据追溯工具
- 安全提示工具
- 教学演示工具
- 竞赛原型系统

本系统不能替代西门子官方手册、现场安全规程或具备资质的工程人员判断。

## 四、核心功能

### 1. 工业安全问答

系统会对输入问题进行工业场景判断，区分普通知识问题、配置类问题、维护类问题和潜在高风险操作问题。

对于高风险问题，系统会强调安全边界，不给出真实 PLC 控制、写入、下载、启停等操作指令。

### 2. 问题类型分类

系统包含问题分类模块，可对用户问题进行初步类型判断，例如：

- 参数查询
- 接线 / 网络连接类问题
- 安全注意事项
- 维护辅助
- 高风险操作请求
- 信息不足、需要澄清的问题

### 3. 证据置信度评估

系统会判断当前回答是否具备足够证据支撑，并输出证据置信度，例如：

- High
- Medium
- Low
- Conflict

这部分用于提醒用户：当前回答是否可以进入人工复核或教学演示流程。

### 4. 答案-证据一致性检查

系统会检查答案中的关键声明是否能够被当前证据支持，并给出：

- PASS
- REVIEW
- FAIL

如果答案中的部分关键声明没有被证据充分支持，系统会提示需要人工复核。

### 5. 结构化证据卡片

系统会生成结构化证据卡片，包括：

- 页码
- 图文证据编号
- 来源
- 标题
- 模块
- 参数
- 证据片段
- 置信度

这使系统回答具备可追溯性，而不是只输出一段无法验证的文本。

### 6. 图文证据显示

系统已经支持图文证据显示。

当证据卡片中包含页码或图文证据编号，例如：

```text
page: 641
figure_id: page_0641_visual
```

前端会自动尝试查找对应图片：

```text
page_0641.jpg
```

并在 Streamlit 证据卡片面板中直接显示该图文证据。

这样系统不只是显示文本证据，而是能够展示手册页面截图或图文证据页面，从而形成：

```text
回答结果
↓
证据置信度
↓
答案一致性检查
↓
结构化证据卡
↓
原始图文证据
```

这是本项目区别于普通搜索引擎的重要部分。

## 九、实体终端方案

项目采用方案 B：

```text
外置计算主机 + 产品化实体终端外壳
```

当前阶段，笔记本作为外置计算主机，实体盒子作为显示与交互终端的方案正在设计中。

实体终端计划包括：

- 屏幕显示
- 状态指示灯
- Query / Demo / Export Log 按钮
- SafePLC-Assist Box 铭牌
- OFFLINE / READ-ONLY 标签
- PLC CONTROL DISABLED 标签

该实体终端不是 PLC 控制器，不连接真实 PLC，也不执行任何控制动作。

当前公开仓库中已经包含硬件方案文档和物料说明。实体照片和最终演示视频将在后续原型制作完成后补充。
