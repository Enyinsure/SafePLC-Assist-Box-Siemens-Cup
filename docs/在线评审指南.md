# 在线评审指南

本文档为西门子杯线上评审提供推荐阅读路径，帮助评审者快速理解 SafePLC-Assist Box 的仓库结构、核心实现、评测材料、硬件原型设计和当前完成状态。

SafePLC-Assist Box 是工业知识安全问答终端原型，不是普通搜索引擎，也不是 PLC 控制器。

---

## 1. 推荐评审顺序

1. 阅读项目总览：`README.md`
2. 查看中文总说明：`docs/中文说明.md`
3. 查看核心实现：`safeplc_assist_box/`
4. 查看 V1.2 评测报告：`docs/V12评测报告.md`
5. 查看硬件原型设计：`hardware/`
6. 查看竞赛材料：`safeplc_assist_box/competition_docs/`
7. 查看测试与场景报告：`safeplc_assist_box/reports/`

## 4. 评审关注点

评审时建议重点关注：

1. 项目是否有清晰的工业安全边界。
2. 系统是否不仅是普通搜索或简单 RAG 页面。
3. 是否支持安全风险判断。
4. 是否支持 Evidence Confidence 与 Answer-Evidence Check。
5. 是否提供结构化证据卡片与本地图文证据显示。
6. 硬件原型设计是否能支撑产品化终端表达。
7. 评测文件是否体现可量化的模块级行为。

---

## 5. 仓库边界

公开仓库不包含完整西门子手册、完整 OCR 输出、向量库、模型权重、完整图文证据资产、压缩交付包、私钥、token 或环境文件。

这些内容因仓库体积、版权、隐私和安全边界原因不纳入公开仓库。本地演示环境在存在对应图文证据资产时，可以显示本地图文证据。

---

## 6. 当前限制

当前仓库应理解为竞赛导向的原型仓库，而不是完整工业部署包。

- 公开仓库不包含完整手册和完整图文证据资产。
- 当前评测主要关注受控测试集和模块级行为。
- 硬件实体外壳仍在进行中。
- 最终照片和演示视频将在后续完善阶段补充。

---

## 7. 总结

SafePLC-Assist Box 是离线、只读的工业知识问答和证据复核原型。它不连接真实 PLC，不接入 TIA Portal，不执行 PLC 控制动作，也不替代西门子官方手册和具备资质的工程师判断。
