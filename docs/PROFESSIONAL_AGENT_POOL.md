# Professional Agent Pool

Implemented specialists:

- Parameter Agent: table and text evidence for values, units, order numbers, and module parameters.
- Figure Agent: figure IDs, page locations, interface and panel layout.
- Wiring Agent: terminal definitions, wiring constraints, installation notes, and cautious safety handling.
- Topology Agent: PROFINET, HMI, CPU, IO and device relationships.
- Troubleshooting Agent: alarms, LED states, communication faults, and check order.
- EMC Agent: grounding, shielding, cable layout, and environment requirements.
- Safety Boundary Agent: industrial operation refusal and offline/read-only alternatives.
- Work-order Agent: structured maintenance record preparation.

Every agent has an independent role description, task input, tool list, structured result, evidence IDs, confidence, latency, tool call count, and abstain capability.
