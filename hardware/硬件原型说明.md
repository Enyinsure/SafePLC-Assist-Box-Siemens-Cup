# SafePLC-Assist Box 硬件原型说明

本文档说明 SafePLC-Assist Box 的硬件原型设计。硬件部分的目标是让软件原型具备产品化工业知识问答终端的外观和交互表达，而不是停留在普通网页演示。

实体终端不是 PLC 控制器，不连接真实 PLC，也不执行任何 PLC 控制动作。

---

## 1. 原型方案

项目采用方案 B：

```text
外置计算主机 + 产品化实体终端外壳
```

在该方案中，笔记本或小型主机作为外置计算主机运行 Streamlit 软件界面；实体终端外壳用于提供显示区域、交互元素、状态指示、标签和产品识别。

当前硬件设计重点是产品形态和安全边界表达。实体外壳仍在进行中。

---

## 2. 设计目标

硬件原型用于支持以下目标：

- 将系统呈现为工业知识安全问答终端。
- 为竞赛评审提供可见的产品形态。
- 清晰展示离线、只读和不控制 PLC 的边界。
- 将知识辅助与真实 PLC 控制明确分离。
- 通过状态指示灯表达软件安全状态。
- 为后续照片和演示视频提供实体基础。

## 4. 计划组件

| 组件 | 作用 |
|---|---|
| 外置主机 | 运行 SafePLC-Assist Box 软件 |
| 终端外壳 | 提供工业产品形态 |
| 显示区域 | 展示 Streamlit 产品界面 |
| SAFE 指示 | 低风险知识问题状态 |
| CAUTION 指示 | 需要复核或上下文不足状态 |
| HIGH_RISK 指示 | 潜在危险操作请求状态 |
| CHECK 指示 | 证据检查完成状态 |
| Query 按钮 | 提交问题的实体交互隐喻 |
| Demo 按钮 | 运行演示案例的实体交互隐喻 |
| Export Log 按钮 | 导出记录的实体交互隐喻 |
| 产品铭牌 | 展示产品名称和版本 |
| 边界标签 | 展示离线、只读和不控制 PLC 的边界 |

---

## 5. 安全边界

前面板应清晰展示：

```text
OFFLINE / READ-ONLY
PLC CONTROL DISABLED
KNOWLEDGE QA ONLY
```

这些标签不是装饰，而是安全设计的一部分。项目涉及 PLC 相关工业知识，必须避免评审者误解为真实 PLC 控制终端。

---

## 6. 硬件不执行的行为

硬件原型不执行：

- 连接真实 PLC
- 接入 TIA Portal
- PLC 通信
- PLC 写入、下载、启停或控制动作
- 真实 IT / OT 网络数据采集
- 替代现场安全流程

---

## 7. 软件与硬件关系

```text
用户
->
SafePLC-Assist Box 实体终端
->
外置计算主机
->
Streamlit 产品界面
->
安全问答
->
Evidence Confidence
->
Answer-Evidence Check
->
本地图文证据显示
```

实体终端提供产品形态和安全边界表达，核心问答与证据复核逻辑仍由软件系统完成。
