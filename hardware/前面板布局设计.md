# 前面板布局设计

本文档说明 SafePLC-Assist Box 实体终端的前面板布局设计。前面板用于把软件安全状态、证据复核状态和产品边界以直观方式展示给评审者。

---

## 1. 设计概念

SafePLC-Assist Box 实体终端是离线工业知识问答系统的产品化显示与交互外壳。

该终端不是 PLC 控制器，不连接真实 PLC，不接入 TIA Portal，也不执行任何控制动作。

项目采用方案 B：

```text
外置计算主机 + 产品化实体终端外壳
```

---

## 3. 面板元素

| 元素 | 说明 |
|---|---|
| 产品铭牌 | 显示 SafePLC-Assist Box 产品名称和版本 |
| 显示区域 | 显示 Streamlit 产品界面 |
| SAFE 指示灯 | 表示低风险知识问题 |
| CAUTION 指示灯 | 表示需要谨慎复核或上下文不足 |
| HIGH_RISK 指示灯 | 表示潜在危险工业操作请求 |
| CHECK 指示灯 | 表示证据检查已经完成 |
| Query 按钮 | 提交问题的实体交互隐喻 |
| Demo 按钮 | 运行演示案例的实体交互隐喻 |
| Export Log 按钮 | 导出记录的实体交互隐喻 |
| OFFLINE / READ-ONLY 标签 | 表示离线只读边界 |
| PLC CONTROL DISABLED 标签 | 表示不具备 PLC 控制能力 |
| KNOWLEDGE QA ONLY 标签 | 表示仅用于知识问答和证据复核 |

---

## 4. 指示灯逻辑

| 指示灯 | 触发条件 | 含义 |
|---|---|---|
| SAFE | 低风险知识问题 | 适合进行知识解释 |
| CAUTION | 中风险问题、证据不足或上下文不完整 | 建议人工复核 |
| HIGH_RISK | 高风险 PLC 操作请求 | 不提供可执行控制指令 |
| CHECK | Evidence Confidence 或 Answer-Evidence Check 完成 | 已进行证据层复核 |

---

## 5. 软件到面板映射

| 软件状态 | 前面板指示 |
|---|---|
| 低风险知识查询 | SAFE |
| 缺少关键上下文 | CAUTION |
| 中风险或需要复核的回答 | CAUTION |
| 高风险 PLC 操作请求 | HIGH_RISK |
| Evidence Confidence 完成 | CHECK |
| Answer-Evidence Check 通过或完成 | CHECK |
| 发现无证据支撑声明 | CAUTION |
| 检测到不安全控制请求 | HIGH_RISK |

该映射让实体终端不只是屏幕外壳，而是能表达工业安全评审状态的产品原型。
