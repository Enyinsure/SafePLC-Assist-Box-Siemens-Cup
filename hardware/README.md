# SafePLC-Assist Box Hardware Prototype

## Scheme B

External computing host + productized terminal shell.

## Current Implementation

- Laptop as external computing host
- Physical box as display and interaction terminal
- Screen for UI display
- SAFE / CAUTION / HIGH_RISK / CHECK status indicators
- Query / Demo / Export Log buttons
- SafePLC-Assist Box V1.2 nameplate
- OFFLINE / READ-ONLY label
- PLC CONTROL DISABLED label

## Boundary

The physical terminal is not a PLC controller. It does not connect to real PLC devices and does not execute control actions.
