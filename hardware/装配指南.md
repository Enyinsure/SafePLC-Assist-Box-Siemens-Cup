# 装配指南

本文档说明 SafePLC-Assist Box 实体原型的计划装配流程。当前阶段以原型规划和终端布局设计为主，实体外壳、标签、指示灯和最终照片仍在后续完善阶段。

---

## 1. 当前方案

项目采用方案 B：

```text
外置计算主机 + 产品化实体终端外壳
```

笔记本作为外置计算主机运行软件系统，实体盒子作为显示和交互终端。终端用于呈现工业产品形态，同时保持离线、只读、不连接真实 PLC 的安全边界。

---

## 2. 装配目标

实体原型的目标是把软件系统转化为可见的工业终端形态，并清晰表达：

- 系统仅用于工业知识问答。
- 系统不连接真实 PLC。
- 系统不接入 TIA Portal。
- 系统不执行 PLC 写入、下载、启停或控制动作。
- 系统提供证据辅助和安全提醒。

---

## 3. 计划组件

| 组件 | 说明 |
|---|---|
| 外置主机 | 运行 SafePLC-Assist Box 软件的笔记本或小型主机 |
| 外壳 | 工业风格终端外壳 |
| 显示屏 | 小型 HDMI / USB 显示屏或类似显示设备 |
| 按钮 | Query / Demo / Export Log |
| 指示灯 | SAFE / CAUTION / HIGH_RISK / CHECK |
| 标签 | OFFLINE / READ-ONLY、PLC CONTROL DISABLED、KNOWLEDGE QA ONLY |
| 电源 | 根据显示模块选择 USB 或外部电源 |
| 固定件 | 螺丝、支架、粘贴标签和内部支撑件 |

---

## 4. 计划装配步骤

1. 准备外壳。
2. 标记前面板布局。
3. 安装显示区域或预留显示窗口。
4. 标记状态指示灯位置。
5. 标记 Query / Demo / Export Log 按钮位置。
6. 安装 SafePLC-Assist Box 产品铭牌。
7. 粘贴安全边界标签。
8. 将显示屏连接到外置计算主机。
9. 在外置主机运行 Streamlit 产品界面。
10. 确认未连接任何真实 PLC 控制接口。
11. 确认界面和前面板均显示离线只读边界。
12. 测试演示问题、Evidence Confidence、Answer-Evidence Check 和证据卡片显示。

---

## 5. 安全核查清单

| 核查项 | 预期结果 |
|---|---|
| 真实 PLC 连接 | 未连接 |
| TIA Portal 连接 | 未连接 |
| PLC 写入 / 下载 / 控制功能 | 未实现或不可用 |
| IT / OT 网络数据采集 | 不采集 |
| 证据卡片面板 | 软件界面可用 |
| 本地图文证据显示 | 本地演示环境可用 |
| 安全边界标签 | 前面板可见 |

---

## 6. 软件与硬件关系

实体盒子不是独立 PLC 控制器，而是 SafePLC-Assist Box 软件系统的产品化外壳。

```text
用户
->
实体终端界面
->
外置计算主机
->
SafePLC-Assist Box Streamlit 界面
->
安全问答 / Evidence Confidence / Answer-Evidence Check
```

---

当前硬件工作聚焦于原型设计文档。最终实体外壳、照片和演示视频将在硬件原型完成后后续补充。
